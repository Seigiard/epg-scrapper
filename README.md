# IPTV playlist and EPG scrapper for personal use

## Development

Run `npm ci` to install dependencies and Lefthook's pre-commit hook. It checks
staged JavaScript syntax with `node --check` and staged whitespace. These checks
do not fetch EPG data or update generated playlists.
